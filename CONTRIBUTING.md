# Contributing

Contributions are welcome.

1. Fork the repository and create a focused branch.
2. Make the change without unrelated formatting or dependency churn.
3. Run `npm run check`, `npm run build` and `cargo check --manifest-path src-tauri/Cargo.toml`.
4. Open a pull request describing the behavior change and the platforms you tested.

Keep Markdown input handling security-conscious. Do not add telemetry, network services or secret material without a separate design discussion.
